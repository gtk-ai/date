# date

Filtro externo [`subprocess/v1`](HOWTO.md) para el comando `date`. Este repositorio sirve también como **plantilla** para crear nuevos módulos gtk-ai.

- **Módulo:** `github.com/gtk-ai/date`
- **ID:** `gtk-ai/gtkai-date`
- **Instalación:** `gtkai filter install github.com/gtk-ai/date@v0.10.0`
- **Guía para crear módulos:** [HOWTO.md](HOWTO.md)
